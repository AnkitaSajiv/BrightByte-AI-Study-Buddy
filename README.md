# 🌟 BrightByte — AI Study Buddy

An interactive AI-powered learning assistant built with Python and Streamlit, 
designed to make self-study smarter, more structured, and more engaging.

---

## ✨ Features

- 🤖 **AI Explanations & Summaries** — Ask any topic and get instant, 
  clear explanations powered by Google Gemini AI
- 📝 **Quiz Generator** — Auto-generates quizzes to test your understanding
- ⏱️ **Pomodoro Timer** — Built-in focus timer to manage study sessions
- 📓 **Notepad** — Take and save notes without leaving the app
- 🌙 **Dark Mode UI** — Sleek, distraction-free interface built with Streamlit

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Core language |
| Streamlit | Web app framework |
| Google Gemini AI | AI explanations & quiz generation |
| REST API | Gemini API integration |

---

## 🚀 How to Run Locally

1. Clone the repository
   git clone https://github.com/AnkitaSajiv/BrightByte-AI-Study-Buddy.git

2. Install dependencies
   pip install -r requirements.txt

3. Add your Gemini API key
   Create a .env file and add:
   GEMINI_API_KEY=your_api_key_here

4. Run the app
   streamlit run app.py
